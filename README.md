# 🎮 Unbeatable Tic Tac Toe

A fully featured Tic Tac Toe game built with HTML, CSS and JavaScript.

## 🌐 Live Demo
[Play the Game]https://haseebgame.netlify.app/
https://haseebgame.netlify.app/

## ✨ Features
- 🤖 Unbeatable AI using Minimax Algorithm with Alpha-Beta Pruning
- 🌐 Online Multiplayer using Firebase Realtime Database
- 🏆 Tournament Mode (Best of 3 and Best of 5)
- 💬 Live Chat during online games
- 📊 Statistics Dashboard with Pie Chart
- 🔥 Heatmap showing most clicked cells
- 🎨 Custom Symbols and Color Themes
- 🔊 Sound Effects with Mute Option
- ⚡ Fair Turn System in Online Mode
- 📱 PWA — Installable as Mobile App

## 🛠️ Technologies Used
- HTML5, CSS3, JavaScript
- Firebase Realtime Database
- Chart.js for Statistics
- Web Audio API for Sounds
- PWA with Service Worker

## 🤖 AI Algorithm
The AI uses the **Minimax Algorithm** with **Alpha-Beta Pruning**.
It evaluates all possible future moves and always picks the optimal one.
On Hard difficulty it is completely unbeatable.

## 🚀 How to Run
Simply open index.html in any browser or visit the live demo link above.
